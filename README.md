# ИГЛА

Программа для расчёта **сопла внешнего расширения** (пробкового, аэроспайка)
по методу Ангелино: контур центрального тела, тяга и удельный импульс на 
высотах 0–50 км, сравнение с идеальным колоколом той же степени расширения.

> **Статус: скелет.** Модель параметров, формат файла проекта, CLI и окно
> собираются и проверяются в CI. Физика (`igla_core::gas`, `::contour`,
> `::performance`) переносится следующим шагом из работающего прототипа со
> сверкой результатов.

## Сборка

```
just build      # или cargo build --workspace
just ci         # то же, что гоняет CI: fmt + clippy + тесты
just --list     # все рецепты
```

Версия тулчейна закреплена в `rust-toolchain.toml`. Под Linux окну нужны
системные библиотеки: `libxkbcommon-dev libwayland-dev libx11-dev
libxrandr-dev libxi-dev libxcursor-dev libgl1-mesa-dev`.

## Использование

```
igla check examples/annular-lh2.toml   # проверить файл проекта, показать СИ-параметры
igla docs                              # методические указания
igla-gui                               # окно
```

## Устройство

| Крейт | Что делает |
|---|---|
| `igla-core` | вся физика и геометрия; ни файлов, ни аргументов, ни отрисовки |
| `igla-cli` | бинарник `igla` — для скриптов, пакетных прогонов и CI |
| `igla-gui` | окно на `egui`; тот же расчёт, что в CLI |

Три правила, на которых держится ядро:

1. **Только СИ внутри.** Бары, миллиметры и километры живут исключительно в
   `igla_core::project` — на границе с файлом проекта.
2. **Никакого ввода-вывода в ядре.** Поэтому его одинаково зовут CLI, окно и
   (позже) Python-биндинг.
3. **Невалидный ввод — ошибка, а не тихая поправка.** ε = 0.8 отвергается с
   внятным сообщением, а не подменяется на 1.05.

Файл проекта — TOML с обязательным `schema = 1`; взаимоисключающие параметры
(схема сопла, способ задания расчётной точки, топливо) заданы вариантами, так
что «поправил ε, а режим стоял по перепаду давления» не собирается.

## Границы модели

Метод Ангелино (1964): приближённое построение по течению Прандтля–Майера,
постоянный γ, идеальный газ, без пограничного слоя и без характеристической
сетки. Метод характеристик — предмет отдельной работы; модуль `gas` намеренно
не переплетён с `contour`, чтобы термодинамику можно было забрать как есть.
